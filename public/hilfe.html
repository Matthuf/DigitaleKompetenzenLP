Hilfe und häufige Fragen

Hilfe und häufige Fragen

Die Selbsteinschätzung zeigt das eigene Kompetenzprofil in sechs Bereichen digitaler Kompetenzen. Grundlage ist der europäische Referenzrahmen DigCompEdu.

Für Lehrpersonen

Wie nehme ich teil?

Die Schulleitung verschickt zu Beginn einer Erhebung einen Link. Über diesen Link startet die Teilnahme. Sie dauert etwa 20 Minuten und lässt sich jederzeit unterbrechen. Die Antworten werden laufend gespeichert.

Wozu dient der persönliche Code?

Der Code ersetzt Name und E-Mail-Adresse. Mit ihm lässt sich die Selbsteinschätzung fortsetzen, das Profil wieder öffnen und bei einer späteren Erhebung der Vergleich mit dem letzten Mal ansehen. Der Code lässt sich kopieren, als Datei speichern oder per E-Mail an sich selbst senden. Solange man angemeldet ist, zeigt «Meinen Code anzeigen» ihn jederzeit wieder an.

Ich habe meinen Code verloren.

Der Code lässt sich nicht wiederherstellen, weil nirgends gespeichert ist, wem er gehört. Ist ein Browser noch angemeldet, zeigt «Meinen Code anzeigen» ihn dort an. Sonst über den Link der Schulleitung mit «Zum ersten Mal hier» neu beginnen. Frühere Profile sind dann nicht mehr erreichbar.

Was bedeutet «Auf diesem Gerät angemeldet bleiben»?

Ohne Häkchen endet die Anmeldung, wenn der Browser geschlossen wird. Mit Häkchen bleibt man 90 Tage angemeldet. Das nur auf dem eigenen Gerät wählen, nie auf gemeinsam genutzten Geräten im Schulhaus.

Was bedeuten die sechs Stufen?

Pro Frage gibt es sechs Aussagen, von «Einsteigen» (I) über «Entdecken», «Anwenden», «Integrieren» und «Entwickeln» bis «Weitergeben» (VI). Gewählt wird die Aussage, die das eigene Handeln am besten beschreibt. Wer in einem Bereich bisher keine Gelegenheit hatte, wählt diese Option. Sie fliesst nicht in die Werte ein.

Was sieht die Schulleitung?

Die Schulleitung sieht keine einzelnen Profile, sondern nur zusammengefasste Werte der ganzen Schule, und dies erst ab fünf abgeschlossenen Teilnahmen. Wer das eigene Profil zum Beispiel für das Mitarbeitendengespräch zeigen möchte, druckt es aus oder speichert es als PDF.

Kann ich meine Daten löschen?

Ja. Im Profil «Meine Daten löschen» wählen. Damit werden alle Teilnahmen zu diesem Code endgültig gelöscht.

Für Schulleitungen

Wie erhalte ich einen Zugang?

Das Amt für Volksschulen und Sport richtet für jede Schule einen Zugang ein. Beim ersten Anmelden wird ein eigenes Passwort festgelegt.

Wie läuft eine Erhebung ab?

Unter «Für Schulleitungen» eine Erhebung eröffnen, zum Beispiel «Herbst 2026», und den Link ans Kollegium weitergeben. Auf Wunsch eigene Fragen der Schule ergänzen. Die Auswertung erscheint, sobald genügend Teilnahmen abgeschlossen sind. Am Ende die Erhebung schliessen.

Was sind eigene Fragen der Schule?

Bis zu 15 zusätzliche Fragen pro Erhebung, als Zustimmungsskala, eigene Stufenaussagen, Auswahl oder Freitext. Sie erscheinen am Schluss des Fragebogens und werden getrennt vom Kompetenzprofil ausgewertet.

Ohne Internet

Die Offline-Version läuft als einzelne Datei im Browser. Alle Antworten bleiben auf dem eigenen Gerät. Schulleitungen können darin eine Schulversion mit eigenen Fragen erstellen und die Ergebnisdateien des Kollegiums auswerten.
