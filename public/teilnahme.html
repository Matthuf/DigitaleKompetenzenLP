Wo stehe ich beim Unterrichten mit digitalen Medien?

Die Selbsteinschätzung zeigt das eigene Kompetenzprofil in sechs Bereichen. Sie dauert etwa 20 Minuten und lässt sich jederzeit unterbrechen.

Angaben zum Arbeitsumfeld (freiwillig)

Nach dem Start gibt es einen persönlichen Code. Damit lässt sich die Selbsteinschätzung später fortsetzen, das Profil wieder ansehen und bei einer nächsten Erhebung vergleichen. Der Code ist nicht mit dem Namen verknüpft.

Schon einmal teilgenommen? Mit persönlichem Code weiterfahren

Code verloren?

Der Code lässt sich nicht wiederherstellen, weil nirgends gespeichert ist, wem er gehört. Solange ein Browser noch angemeldet ist, kann der Code dort unter «Meinen Code anzeigen» abgerufen werden. Sonst oben mit «Selbsteinschätzung starten» neu beginnen. Frühere Profile und der Vergleich mit früheren Erhebungen sind dann nicht mehr erreichbar.

Datenschutz: Die Schulleitung sieht keine einzelnen Profile, sondern nur zusammengefasste Werte der ganzen Schule. Das eigene Profil lässt sich mit dem Code jederzeit vollständig löschen.

      Bisher keine Gelegenheit

      Hier fehlen möglicherweise Voraussetzungen wie Geräte, Plattformen oder ein Auftrag. Das ist ein Thema für das Gespräch mit der Schulleitung, keine Kompetenzlücke.

        Wie weiter mit dem Profil?

        1. Ein bis zwei Entwicklungsfelder auswählen. Die Aussage der nächsten Stufe eignet sich als konkretes Ziel.
        2. Das Profil im Mitarbeitendengespräch einbringen: «Drucken oder als PDF sichern» und mitnehmen. Die Schulleitung sieht es sonst nicht.
        3. Wo «keine Gelegenheit» steht, mit der Schulleitung klären, ob Geräte, Plattformen oder ein Auftrag fehlen.
        4. Bei der nächsten Erhebung mit dem persönlichen Code teilnehmen. Dann zeigt das Profil die Entwicklung seit dem letzten Mal.
